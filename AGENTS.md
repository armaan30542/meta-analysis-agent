# AGENTS.md

Instructions for AI coding agents (Codex, Claude Code, others) working in this repository.

## If you are asked to run a meta-analysis

Follow `skills/meta-analysis/SKILL.md` step by step. It is written for Claude Code but works
for any agent with two substitutions:

- `${CLAUDE_PLUGIN_ROOT}/bin/metakit` means `./bin/metakit` from this repo's root.
- `${CLAUDE_SKILL_DIR}/references/` means `skills/meta-analysis/references/`.
- "Launch two `extractor` subagents" means: perform the extraction in `agents/extractor.md`
  twice, independently, into `extraction/` and `extraction_b/`. If you cannot run parallel
  agents, do extraction B in a fresh session that has not seen extraction A.

Non-negotiable, whichever agent you are:

1. Never compute statistics yourself. metakit computes; you extract and explain.
2. Every extracted number carries an exact quote from the full-text file; run
   `./bin/metakit validate` and fix every error by re-reading the source.
3. The human approves the protocol, resolves ambiguous extractions, and confirms risk of bias and GRADE.

## If you are asked to change the code

- Run the suite before and after: `pip install -r requirements.txt pytest && pytest -q`
  (about 15 s). All tests must pass.
- Any change to `metakit/models.py`, `bias.py`, `effects.py`, `convert.py` or
  `sensitivity.py` must keep agreement with R/metafor. Reference values are generated by
  `Rscript r/make_reference.R`; add a new case there for any new estimator and a test in
  `tests/test_models.py` or `tests/test_convert.py`.
- `python -m metakit benchmark` must still print `ALL BENCHMARKS PASSED`.
- Keep the validator strict. A change that makes `tests/test_extraction.py` pass by loosening a
  check is a regression.
- Do not add dependencies beyond `requirements.txt` without a strong reason; the tool must
  install in about a minute on a student laptop.

## Layout

```
metakit/            Python package (the CLI is metakit/cli.py)
  models.py         random/fixed-effects models, meta-regression, tau2 CI
  bias.py           Egger, Begg, trim-and-fill
  sensitivity.py    leave-one-out, cumulative, subgroups
  effects.py        effect sizes (escalc equivalent)
  convert.py        SE/CI/median -> SD, merging groups, units
  extraction.py     extraction schema + provenance validator
  harmonize.py      extraction -> effect sizes with an audit trail
  analysis.py       runs everything per outcome
  report.py         writes report/report.md
  retrieve.py       PubMed / Europe PMC full texts, PDF -> text
  ingest.py         reads the systematic review's included-studies list
  reconcile.py      dual-extraction comparison
  rob.py, grade.py  risk of bias, GRADE suggestions
  plots.py          figures
skills/, agents/    Claude Code plugin (skill + extractor subagent)
r/                  metafor reference generator and cross-check
benchmarks/         published meta-analyses reproduced end to end
tests/              pytest suite
docs/               plain-language and technical docs, GitHub Pages site
```
